## 故障预案（对应材料"网络/MCP 失效时展示缓存"）

| 故障 | 预案 |
|---|---|
| 网络/API 失效 | Tool 自动重试 3 次 → 返回缓存 JSON（`data/cache/tool_cache.json`，标记 cached=true）→ 问答走离线 BM25 模式（无需密钥） |

| 现场随机问题 | 固定题集优先（12 题已验证），越界问题演示"安全拒答"能力 |
